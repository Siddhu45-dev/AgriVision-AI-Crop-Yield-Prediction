# AgriVision AI – Crop Yield Prediction System

## About the Project
AgriVision AI is a Machine Learning-based application that estimates crop yield using historical agricultural data.

## Features
- Crop yield prediction
- Interactive agricultural dashboard
- Crop and seasonal analytics
- Model performance evaluation
- Prediction history export
- Weather forecasts and farming insights

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Extra Trees Regressor
- Streamlit
- Plotly
- Open-Meteo API

## Dataset
The project uses historical crop data containing crop type, year, season, state, area, rainfall, fertilizer, pesticide, production and yield information.

## Installation


pip install -r requirements.txt


## Run the Application


streamlit run app.py


## Train the Model

If the trained model file is not available, run:


python train_model.py


## Disclaimer
Predictions are estimates based on historical data and are not guaranteed agricultural outcomes.
